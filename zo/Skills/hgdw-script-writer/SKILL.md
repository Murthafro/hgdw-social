## Step 1: Determine Format

Ask or infer which format fits the idea:

| Format | Best for | Builds |
|---|---|---|
| Talking head (DTC) | Trust, personality, offers | Deep connection |
| Silent film (b-roll+text) | Storytelling, transformation, reach | Broad awareness |
| Carousel | Step-by-step, lists, engagement | Comments + saves |

## Step 2: Identify the Two-Layer Story (Mystery Box)

Before scripting, answer:
- **Surface story:** What is this video functionally about?
- **Real story:** What is it REALLY about emotionally?

Examples:
- Surface: "how to batch content in 2 hours" → Real: "how to stop letting perfectionism steal your presence with your family"
- Surface: "why I stopped niching down" → Real: "what it feels like to finally stop hiding parts of yourself"

## Step 3: Write the Script

### If Talking Head:

**Hook (first 3 seconds):**
- Use symptom-first framing (patient language, not doctor language)
- Pair spoken hook with on-screen text overlay (58% watch muted)
- Open with a question or unresolved moment, NOT the answer
- Use "I" framing if not yet established, "you" framing if established

**Body — Problem-Pursuit-Payoff:**
- **Problem** (0-5 sec): Open with the struggle. Viewer sees themselves.
- **Pursuit** (5-35 sec): Show the messy middle — what you tried, what was hard, what shifted. Don't skip this. Don't rush from problem to payoff.
- **Payoff** (~40 sec): The transformation or realization.

**Re-hooks throughout:**
- Layer new mystery boxes: "But that's not what actually moved the needle — I'll show you that in a second"
- Use structural shifts (analogy → personal story → teaching → CTA)
- Delay the reveal as long as possible without losing the viewer

**CTA (final 5 sec):**
- ONE clear next step. Follow, comment a keyword, save, link in bio.

**Script format:**
```
[ON-SCREEN TEXT]: Hook text for muted viewers
[SPOKEN]: "Hook — spoken version"

[SPOKEN]: "Problem — the struggle"

[SPOKEN]: "Pursuit — what I tried / what was hard"

[SPOKEN]: "Payoff — what changed"

[ON-SCREEN TEXT]: CTA text
[SPOKEN]: "CTA — clear next step"
```

**Production notes:**
- Film one line at a time (look at camera → say line → look at script → next line)
- No teleprompter — shows in the eyes
- Cut all dead air, filler words, "um"s
- 3.5 min raw → tight 90 sec final

### If Silent Film:

**Slide/frame plan:**

1. **Frame 1 — Struggle** (with timestamp on screen: year/age/month)
   - Open with a real hardship, not success
   - Text: [the struggle — patient language]

2. **Frame 2-4 — Pursuit** (music builds)
   - Show the messy middle
   - One idea per frame
   - Pacing check: can you read each text line aloud before the next frame?

3. **Frame 5 — Payoff**
   - The transformation
   - Text: [the realization]

4. **Frame 6 — CTA**

**Music direction:** Choose music with rising action — starts low, builds. Implies transformation is coming. The viewer subconsciously knows the story goes somewhere.

**Checklist:**
```
□ Opens with real struggle (not a win, not a flex)
□ Music has rising action
□ Timestamp on screen (year, age, or time reference)
□ Text pacing: every line readable aloud before next frame
□ Ends with payoff
```

### If Carousel:

**Slide plan:**
1. **Slide 1 — Hook** (largest text, stops the scroll)
2. **Slides 2-8 — One idea per slide** with repeated structural pattern
3. **Final slide — CTA** (follow, comment keyword, save)

**Checklist:**
```
□ Text readable (light text + border, or light on dark)
□ Slide 1 = hook (the "Stop" job)
□ Hook = largest text on slide
□ Visuals support text, don't compete
□ One idea per slide
□ Sound/music track attached (for Reels tab eligibility)
□ Portrait/full-frame
□ Repeated structural pattern across slides
□ Clear CTA on final slide
```

## Step 4: Quality Checks

Run the script through:

**Good-format checklist (all formats):**
```
□ Strong hook — stops scroll, creates curiosity, calls out specific person/problem
□ Real value — specific, useful, resonant; not generic
□ Re-hooks throughout — structural shifts that sustain momentum
```

**Mystery Box checklist:**
```
□ Hook = question or unresolved moment (not the answer)
□ At least one new question mid-video (re-hook via curiosity)
□ Reveal delayed as long as possible
□ Two-layer story identified (surface + emotional truth)
□ At least one thing intentionally withheld
```

**Voice check:**
- Does it sound like HGDW? Bold, playful, warm, no jargon, no hedging
- Would Alex stop scrolling for this?
- Is it audience-first, not self-centered?
- Is the value specific, not generic?
